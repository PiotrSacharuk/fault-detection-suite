## Getting Started

### Prerequisites
- Python 3.10+

### Environment Setup

1. **Create and activate a virtual environment:**
   - **Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
